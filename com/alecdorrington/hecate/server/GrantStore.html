Hecate/com.alecdorrington.hecate/com.alecdorrington.hecate.server/GrantStore

GrantStore

com.alecdorrington.hecate.server.GrantStore
See theGrantStore companion object
final class GrantStore(tables: AuthTables, db: Transactor)

A store of grants: which principals hold which access over which resources, named in the host's own terms. Access is resolved against the principals the caller supplies; Permissions joins this with GroupStore.

Writes are returned as actions to compose into the host's transactions. A principal holds at most one grant per resource only if the caller locks the resource's own row earlier in the same transaction before grant, raise or revokeOver, as the check-then-insert races under READ COMMITTED otherwise. A resource created in the same transaction needs no lock. A duplicate that slips through confers only its highest level, and the next grant replaces it.

Value parameters

db

The database to run queries against.

tables

The tables the grants are stored in.
