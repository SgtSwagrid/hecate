AuthEndpoints

com.alecdorrington.hecate.server.tapir.AuthEndpoints
See theAuthEndpoints companion object
final class AuthEndpoints(auth: AuthService, wording: Option[String] => Wording = ...)

A server of the endpoints in AuthApi, backed by an AuthService, with the security logic of every endpoint built on AuthApi.secured, the host's included.

Value parameters

auth

The service that answers the requests.

wording

The wording of refusals for the language a request names, or for None when it names none.
