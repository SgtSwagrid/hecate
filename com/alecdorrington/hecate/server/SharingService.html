SharingService

com.alecdorrington.hecate.server.SharingService
See theSharingService companion object
final class SharingService(grants: GrantStore, links: LinkStore, groups: GroupStore, db: Transactor, resources: Resource => DBIO[Option[String]], access: Option[(User, Resource) => IO[Option[Access]]] = ..., report: Throwable => IO[Unit] = ..., affected: Affected => IO[Unit] = ...)

A service that lets a resource's owners see and change who holds it, and manage its invite link. A resource is never left with nobody holding Access.Own, no link grants Access.Own, and only a principal the owner may address (GroupStore.mayAddress) is granted anything. Every change locks the resource's row first, through resources, so that two owners giving up ownership at once cannot each see the other still holding it.

Value parameters

access

The host's resolution of a user's access to a resource, or None for stored grants alone (Permissions.access).

affected

The hook told whom each committed change concerns (see Affected).

db

The database the stores use.

grants

The store of grants.

groups

The store of groups.

links

The store of invite links.

report

The handler of failures whose detail must not reach the client.

resources

The lookup of a resource's name that locks its row until the transaction ends, yielding None for a missing resource, as for LinkService.
